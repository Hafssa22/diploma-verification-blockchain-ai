# AI Fraud Detection Service

## Description
Microservice IA permettant la détection intelligente de faux diplômes.

## Technologies
- Python
- Flask
- Scikit-learn
- RandomForest
- Pandas

## Fonctionnalités
- Détection de diplômes frauduleux
- Analyse des anomalies
- Score de confiance
- API REST
